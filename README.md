# Sebastian Beltran — Portfolio

Portfolio personal de **Sebastian Beltran**, desarrollador full stack (Berazategui, Argentina).
Sitio estático, sin dependencias ni pasos de build: HTML + CSS + JavaScript.

**Ver en vivo:** https://sebasbel2007.github.io/Portfolio/

## Qué contiene

- **15 proyectos** con app en vivo (14 apps web + 1 app de escritorio); 14 repositorios públicos y 1 privado (proyecto final con datos sensibles).
- Sidebar de navegación con scrollspy, buscador y filtros por sección.
- Credenciales de las apps de demostración incluidas en cada tarjeta.
- CV 2026 en PDF descargable.
- Diseño responsive (escritorio con sidebar fija, móvil con menú lateral), accesible y sin errores de consola.

## Estructura de secciones

| Sección | Proyectos |
| --- | --- |
| **Con servidor** (Render) | Rotiseria QR · Plataforma de Cursos + diagrama · Natacion SMI + lista de materiales · S.A.D (proyecto final, repo privado) |
| **Estaticos** (GitHub Pages / Netlify) | Firebase Notas · Nexo Destinos · Sistema Preceptora + manual |
| **Personales** (+ proyectos viejos) | App Meditar · Juego Matias · Museo · Voley · Sistema de Vuelos (Python) |

## Cómo verlo

Abrí `index.html` directo en el navegador, o serví la carpeta:

```bash
python -m http.server 8123
```

## Archivos

- `index.html` — estructura y contenido
- `style.css` — sistema de diseño completo
- `script.js` — filtros, buscador, scrollspy, lightbox, copiado al portapapeles
- `img/` — CV, miniatura de video y assets
- `img app/` — capturas de cada proyecto
- `links.txt` — fuente de verdad de repositorios, apps y credenciales
